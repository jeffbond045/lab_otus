# Сверка сохранённых конфигураций с топологией EVE-NG

Источник: файл `2020-02.unl`, извлечён из `_Exports_unetlab_export-20261117-154721.zip`. Устройства: R16, R17, R18, R32, SW9, SW10. Конфигурации `configs/*.cfg` санитизированы: строки с локальными secret удалены.

- R17–R18: 10.20.200.64/30 (`.65/.66`), IPv6 `FD41:D52F:5041:5001::/127` (`::1/::`).
- R16–R32: 10.20.200.72/30 (`.74/.73`), IPv6 `FD41:D52F:5041:5001::C/127` (`::C/::D`).
- R17–SW9: 10.20.200.0/30 (`.2/.1`), SW9 IPv6 отсутствует.
- R17–SW10: 10.20.200.4/30 (`.5/.6`), SW10 IPv6 отсутствует.
- R16–SW9: 10.20.200.8/30 (`.10/.9`), SW9 IPv6 отсутствует.

- SW9 Loopback0: 10.20.255.9/32, SVI VLAN10 192.168.20.1/24.
- SW10 Loopback0: 10.20.255.18/32, SVI VLAN20 192.168.21.1/24.
- VPC8 eth0: 192.168.20.20/24, gateway 192.168.20.1; VPC eth0: 192.168.21.21/24, gateway 192.168.21.1 (из сохранённых VPC config, без живого ICMP).

## Конфигурационный аудит

| Проверка | Факт | Значение |
|---|---|---|
| R16/R17/R18/R32 EIGRP IPv4 + IPv6 | Есть, AS 2042 | Соответствует изучаемому протоколу |
| R32 изучает только defaults | Подтверждено CLI | Требование выполнено |
| R16 prefix-list `LOOP_6_deny_test` | В конфиге есть, но нет применяющего `distribute-list` | Не действует в сохранённом экспорте |
| SW9/SW10 EIGRP | Нет | Loopback и сети доступа не распространяются ими через EIGRP |
| SW9/SW10 IPv6 | Нет | IPv6 P2P к SW не завершены |
| R16 статические defaults | Настроены в сторону R18 | Экспериментальная/внутренняя маршрутизация; внешняя связность не подтверждена |
| R18 диагностика | Loopback6 и Loopback18 сохранены | Для воспроизведения кейсов с Null0 |

## Практическая последовательность до окончательной сдачи

1. Донастроить SW9/SW10 IPv4 EIGRP и IPv6 по согласованному плану.
2. Проверить соседства с R16/R17 и между SW, таблицы RIB, L3-связность Loopback и сетей доступа.
3. Повторить R18→SW9/SW10 и R32→SW9/SW10 ping обоих семейств; отдельно проверить VPC, если включены.
4. Проверить исключения из формулировки «только суммарные префиксы» и отразить их в выводах, не скрывая несовпадения.
5. Снять свежие `show running-config`/`show ip route`/`show ipv6 route` после изменения SW, чтобы экспорт перестал быть устаревшим.
