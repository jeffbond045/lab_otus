# Проверка таблиц маршрутизации и соседств

Данные собраны из предоставленных выводов Cisco IOS; таблицы сокращены до значимых записей. Это не полный архив всех команд.

## R18 — входящие агрегаты

```text
IPv4:
D 10.20.200.0/29     via 10.20.200.65, Et0/1 (R17)
D 10.20.200.8/29     via 10.20.200.69, Et0/0 (R16)
D 10.20.200.72/30    via 10.20.200.69, Et0/0 (R16; исключение)
D 10.20.255.8/31     via 10.20.200.65, Et0/1 (R17)
D 10.20.255.16/29    via 10.20.200.69, Et0/0 (R16)
C 10.20.255.24/32    Loopback0

IPv6:
D FD41:D52F:5041:5001::4/126 via FE80::A8BB:CCFF:FE01:1010, Et0/1
D FD41:D52F:5041:5001::8/125 via FE80::A8BB:CCFF:FE01:10, Et0/0
D FD41:D52F:5041:5002::16/128 via Et0/0
D FD41:D52F:5041:5002::17/128 via Et0/1
D FD41:D52F:5041:5002::32/128 via Et0/0
```

По `show ip eigrp neighbors` и `show ipv6 eigrp neighbors`: по два соседа, R16 и R17, Q Cnt 0. Все показанные записи `show ... eigrp topology` — Passive, по одному Successor на агрегат.

## R16 — маршруты и Null0

```text
IPv4:
S* 0.0.0.0/0       via 10.20.200.70 (R18)
D  10.20.200.8/29  is a summary, Null0
D  10.20.255.16/29 is a summary, Null0
D  10.20.255.19/32 via 10.20.200.73 (R32; после исправления network)

IPv6:
S  ::/0           via FD41:D52F:5041:5001::2 (R18)
D  FD41:D52F:5041:5001::8/125 [5/1024000] via Null0
D  FD41:D52F:5041:5002::32/128 via Et0/3 (R32)
```

## R17 — локальные агрегаты

```text
IPv4:
D 10.20.200.0/29  is a summary, Null0
D 10.20.255.8/31  is a summary, Null0
D 10.20.200.8/29  via 10.20.200.66 (R18)
D 10.20.255.16/29 via 10.20.200.66 (R18)

IPv6:
D FD41:D52F:5041:5001::4/126 [5/1024000] via Null0
D FD41:D52F:5041:5001::8/125 via R18 Et0/1
```

## R32 — только EIGRP default

```text
IPv4:
D* 0.0.0.0/0 [90/1024640] via 10.20.200.74, Ethernet0/0
C  10.20.200.72/30 Ethernet0/0
C  10.20.255.19/32 Loopback0

IPv6:
D  ::/0 [90/1024640] via FE80::A8BB:CCFF:FE01:30, Ethernet0/0
C  FD41:D52F:5041:5001::C/127 Ethernet0/0
LC FD41:D52F:5041:5002::32/128 Loopback0
```

R32 имеет по одному EIGRP-соседу в обеих Address-Family (R16, Ethernet0/0), Q Cnt 0. На R32 нет других удалённых маршрутов EIGRP, кроме двух маршрутов по умолчанию.
