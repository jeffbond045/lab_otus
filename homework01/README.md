# Домашняя работа: Проектирование сети

## Адресный план: Москва

Для московской части сети выделен общий суммаризируемый блок:

`10.10.0.0/16`

### Выделенные адресные блоки

| Назначение | Сеть | Маска | Примечание |
|---|---|---:|---|
| Москва — общий адресный пул | `10.10.0.0/16` | `255.255.0.0` | Общий блок для всех внутренних сетей Москвы |
| Пользовательская сеть VPC1 | `10.10.0.0/24` | `255.255.255.0` | Пользовательский VLAN / LAN |
| Пользовательская сеть VPC7 | `10.10.1.0/24` | `255.255.255.0` | Пользовательский VLAN / LAN |
| Пользовательские сети — summary | `10.10.0.0/23` | `255.255.254.0` | Суммарный префикс для двух пользовательских `/24` |
| Внутренние P2P-сети | `10.10.254.0/25` | `255.255.255.128` | Блок для дальнейшего деления на `/30` |
| Loopback-интерфейсы | `10.10.255.0/24` | `255.255.255.0` | Адреса управления; каждому устройству будет назначаться `/32` |

## Принципы адресации

- Все внутренние адреса Москвы выделяются из `10.10.0.0/16`.
- Пользовательские сети `10.10.0.0/24` и `10.10.1.0/24` суммаризируются в `10.10.0.0/23`.
- Блок `10.10.254.0/25` будет разделён на отдельные P2P-подсети `/30`.
- Блок `10.10.255.0/24` зарезервирован под Loopback-интерфейсы; конкретные Loopback будут иметь маску `/32`.
- Пограничные меж-AS линki будут рассмотрены отдельно и пока не включены в блок внутренних P2P-сетей Москвы.

3. Назначить Loopback `/32` каждому сетевому устройству.
4. Назначить IP-адреса VPC и шлюзы по умолчанию.
